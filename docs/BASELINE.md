# 已确认基线 B2 · 2026-10-28

用户于 2026-10-28 确认改为安装时一次 UAC、登录期间管理员协调器常驻、托盘内一次批准；每条独立命令依然重建环境并启动独立进程。具体接口和验收见 [UAC-0.4-CONTRACT](UAC-0.4-CONTRACT.md)。正常批准不再通过独立提权窗口，原 B1 的此项约定由 B2 替代。管理员身份仍为当前用户，未改成 SYSTEM。当前范围按登录会话授权，不以客户端名称建立跨登录自动批准名单。

## 原 B1（历史）

依据用户确认的 discussion/DESIGN-TRUSTED.md：信任所用模型，接受通用管理员执行的部分风险，避免重复 UAC；每条独立命令重建环境，不继承常驻执行器旧环境。

授权到 Windows 登录会话结束/主动关闭，或用户指定截止时间；锁屏不失效。托盘绑定运行，图标变化提示新请求，展示请求及授权列表，提供批准、拒绝、撤销和任务查看。后台不得主动弹 UAC 或抢焦点。批准由用户主动点击，经 UAC 的审批程序确认。普通任务与管理员任务分开；不可静默切换 SYSTEM。持久 shell 显式创建与重建。

一次完整开发，研究材料不作为分期路线。所有显示、UI、UX 设计与代码由 Claude Opus 5.5 medium 承担；主代理负责非 UI、接口和集成。交互所需后台变化通过 docs/UI-ALIGNMENT.md 对齐。

不承诺管理员脚本隔离或回滚，不将服务恢复等同 Agent 自动恢复。宿主审批与 Windows UAC 分离。实际运行身份、环境更新、取消、断线结果与托盘交互必须有独立证据。

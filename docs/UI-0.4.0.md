# PwshMCP 托盘 UI 0.4.0：主窗口内联批准

## 目标
安装时只弹一次 UAC。之后的提权批准都在现有托盘主窗口内完成：选择有效期 → 批准，不开新窗口，不再弹 UAC。

## 交互
- **请求详情 → 「批准此请求」卡片**（仅当执行器就绪时显示）：
  - 说明权限范围：仅限此客户端在本次 Windows 登录中，每条命令都在全新的 PowerShell 环境中运行，不隔离也不撤销更改。客户端名称仅用于显示，不是身份凭据。没有持久的自动批准。
  - 页面内不再放有效期选择器，卡片只保留权限范围说明。
- **底栏有效期链接 → 锚定弹出层**：左下角“有效期：直到注销 ⌃”点击后，在链接正上方弹出轻量浮层（`Popup`，Placement=Top，StaysOpen=false）。它不是二次确认，不滚动页面，也不追加卡片。
  - 浮层内容：标题“有效期”；四个选项（直到注销/1 小时/4 小时/今天结束前），带访问键，并以小字预览截止时间（“注销或重启时结束，锁屏不会”/“至 10月28日 21:05”）；当前选项高亮；底部一行范围说明“适用于 {客户端} 在本次 Windows 登录中发送的所有命令，不只是此任务。”
  - 选择后更新底栏文字并关闭浮层，焦点回到链接。批准仍是单击，经现有 AdminClient 发送，不弹 UAC，也不再确认。
  - 键盘：打开后聚焦当前选项，方向键在选项间循环，Enter 选中，Esc 关闭（不会触发窗口的 Esc 隐藏），Tab 在浮层内循环。点击外部也会关闭，且同一次点击不会重新打开。
  - 以下情况自动关闭，不留残留浮层：切换选中请求或标签页、请求不再待批准或不可编辑、进入发送中、窗口隐藏/最小化/失焦/移动/缩放、切换语言（旧窗口 Release）。发送中或执行器离线/需修复时，链接被隐藏或禁用，`Open` 也会拒绝。
- **底栏**：发送中，批准按钮显示旋转图标和“正在批准…”，并禁止重复提交。失败信息以红色就地显示，请求保持待批准，可直接重试。
- **执行器状态**：页头显示状态标签（检查中/就绪/离线/需修复），悬停可查看详情。状态不可用时：
  - 卡片换成琥珀色提示区，给出安装或修复建议（`scripts\install-desktop.ps1`）和“不会弹出 UAC”的说明，并提供“重新检查”按钮和上次检查时间。
  - 批准与重启按钮禁用。
  - 不会自动回退到 runas。
- **批准成功**：只有当 `Grant.State == Active` 时才视为成功。随后切换到“授权”页并选中该授权，提示“已批准”。如果返回 Ok 但状态不是 Active，按失败显示。
- 恢复执行器（重启）走 `Op.Resume`，处理方式与批准相同。

## 实现
- `Coord.cs`：
  - 执行器状态轮询独立于代理监视器。就绪时每 5 秒、离线时每 3 秒检查一次，失败可立即重试，不阻塞 UI。
  - `Send` 负责发出 `Op.Approve(Id, ExpiresAt UTC)` 和 `Op.Resume`。“直到注销”不发送 ExpiresAt。
  - 异常映射：`UnauthorizedAccess` → 需修复（服务端不受信），超时/IO/取消 → 离线。
  - 传输层可注入，供自测使用。
- `Fmt.Err` 把 `AdminNames` 的错误码（Offline/Forbidden/Invalid/Protected/Worker）映射为中英文文案。
- 常规 `MainVm` 路径不再调用 `Launch.Elevated`。`ApproveWindow`/`ApproveVm` 只保留给显式启动的旧流程。有效期计算已抽到 `Lives`，供两条流程共用。
- 样式：`K.Issue`（批准卡片）、`K.Pop`（浮层卡片，宽 336，带阴影）、`K.Pick`（浮层列表行：悬停/选中/键盘焦点三态）、`K.Blocked`（琥珀提示区）、`K.BusyTpl`（盾牌/旋转图标）。界面延续深色主题，不显示 ID。
- 版本 0.4.0。所有文案位于 `Copy.Inline`/`Copy.Gate`，键名位于 `K`/`Report`。

## 自测（`dotnet src/PwshMcp.Tray/bin/Debug/net8.0-windows/PwshMcp.Tray.dll --render-check artifacts/ui-popup-0.4.0`，250 项，0 失败，见 `ui-selftest.txt`）
使用伪造的传输层，不调用 `Coord.Start()`，不走真实管道，也不触发 UAC。浮层显隐经 `MainWindow.Pop` 接缝替换，不创建弹出窗口句柄。中英文各测一遍：
- 页面：没有 `K.Pick` 单选，也没有“有效期”选择器文字。渲染文件为 `gate-*-inline-720`。
- 浮层：静止时关闭；StaysOpen=false、Placement=Top；关闭时 Esc 不被浮层吞掉。按 AutomationId 点击链接后打开，绑定到当前选中请求，默认选中“直到注销”。
- 浮层内容：取真实浮层卡片渲染，检查无裁切、文案共享、截止时间预览与范围说明齐全、四个选项都在。卡片叠放在链接上方，宽度 720/1000/1400 下均位于窗口内。渲染文件为 `popup-*-{720,1000,1400}`。
- 选择 4 小时：浮层关闭，底栏文字等于 `Picked`，Until 约为 4 小时。渲染文件为 `popup-*-picked-*`。重新打开时选中当前项；Esc 关闭并保留选择；Enter 选中焦点项。
- 切换标签页或取消选中时关闭，且旧链接无法重新打开；Release（换语言路径）关闭已打开的浮层；进入发送中时关闭、链接禁用、`Open` 被拒。
- 在浮层中选 1 小时后批准：发送的 ExpiresAt 约为 1 小时。
- 就绪：批准可用。
- 离线/需修复：批准禁用，提供重新检查；有效期链接隐藏，浮层拒绝打开。渲染文件为 `gate-*-down-*`、`gate-*-broken-*`。
- 被拒（Forbidden）：已发送的 Op/Id/ExpiresAt 约为 1 小时；错误就地显示，可重试。渲染文件为 `inline-*-failed-*`。
- 返回 Ok 但状态为 Pending：不判定为批准成功。
- 直到注销：不发送 ExpiresAt；返回 Active 时接受。
- 发送中：重复提交和切换有效期都被阻止。渲染文件为 `inline-*-sent-*`。
- 文案检查：占位符和访问键在两种语言间一致。

## 遗留与契约说明
- 未用真实管道、真实执行器或 UAC 验证，需由上级完成正式构建、安装和验收。
- 浮层的以下行为只在离线模型中验证过，没有在真实窗口中验证：弹出窗口的实际定位、点击外部关闭及防止重开的 300ms 保护、真实焦点移动与归还、淡入动画、实际显示器 125% 缩放、读屏输出。720px 下英文底栏文字会换成两行。
- 契约只接受安装目录下的 `PwshMcp.Tray.exe`。开发构建的托盘发出批准会收到 Forbidden，界面会如实提示“请从安装位置打开”，不会伪装成功。
- 离线/需修复的详情是固定建议文案。契约的 Status 只返回 Ready/错误码，没有更细的诊断字段；如需精确原因，需要扩展 `AdminResponse`。
- 旧的 `ApproveWindow` 仍会经 UAC 启动，仅限显式命令行使用，常规路径不会进入。

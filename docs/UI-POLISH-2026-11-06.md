# GUI 与文本提示优化（2026-11-06）

## 目标

优化托盘 GUI 显示与中英文文本提示：通知弹窗信息层级、窄窗口排版、状态副文案截断、理由缺省态区分、旧批准窗口一致性。不改变授权模型、协议和既有视觉语言。

## 实施分工

- 主体由 agy CLI `gemini-3.8-flash-high` 完成（会话 `57c853d9`），一次运行 14 分 50 秒。
- 主代理复跑构建、离线渲染自检与两个回归测试，复看 360/480/720/1000/1400 中英截图，并修复两处验收缺陷、恢复两处被过度精简的文案。

## 改动

### 通知弹窗（`NoticeWindow.xaml`、`NoticeWindow.xaml.cs`）

- 顶部补状态标签与请求时间（`Chip` + `Age`），与主窗口详情一致。
- 任务名、理由补字段标签；理由改用 `K.Reason`（缺省文案弱化为 `K.Muted`）。
- 授权范围包进 `K.Scope` 卡片，层级与主窗口、批准窗口统一；范围说明保留在卡片内。
- 等待命令补 `WaitingHead` 章节标题，描述使用 `K.Desc`。
- 滚动区与操作区之间加分隔线；待处理数、结果提示为空时折叠，消除"授权有效期"上方空白断层。
- 结果提示存在时隐藏重复的执行器不可用提示。
- 有效期双列单选改对称间距（`3px` 中缝），两列等宽。
- 批准按钮接入盾牌/加载模板（`K.BusyTpl`）；免打扰改为居中弱化按钮（`K.Quiet`）。

### 主窗口（`MainWindow.xaml`、`Vms.cs`、`Controls.cs`）

- 页头副文案改为 `托盘代理 · 管理员身份` / `Tray broker · Elevated`，1000px 英文不再截断。
- 新增 `All.Wide` 转换器：连接信息区宽度不足 300px 时隐藏副文案，720px 下不再出现单字残影或硬切。
- 底栏内边距 `32,14 → 20,12`，有效期按钮内文本改单行（`NoWrap` + 省略号），720px 下不再折成两行。
- 理由使用 `K.Reason`：缺省"未提供理由。"自动降为次要色。
- 页头错误提示为空时折叠，不再占位。

### 旧批准窗口（`ApproveWindow.xaml`、`ApproveVm.cs`）

- 滚动区接入共享 `K.Scroll` 稳定槽位样式。
- 理由补 `Copy.Detail.Reason` 标题与 `K.Reason` 样式。

### 文案（`Consts.cs`、`Check.cs`）

- `Copy.Conn`：`OwnedBroker`/`ExternalBroker`/`Elevated` 精简为可拼接的短语。
- `Copy.Inline.Failed` 保留"请求仍在等待"的状态保证，去掉冗余的"可以重试"。
- `Copy.Gate.Forbidden` 保留"从已安装位置打开托盘"的行动指引，整体缩短。
- 离线自检的占位理由由 `sample` 改为双语真实运维文案。

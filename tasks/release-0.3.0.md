## 可读的双语授权界面

- 新增中文 / English 切换；托盘与授权窗口共享语言选择，字段位置保持一致。
- 请求、授权、任务优先展示名称与指令描述；技术 ID 保留于详情，授权键仍在授权范围中直接显示。
- PowerShell 命令按窗口宽度折行，支持语法高亮和原文复制；超过 20000 字符时使用纯文本。
- MCP initialize 客户端标题与 --display-name 可提供显示名称，不改变授权身份。
- 新增宿主结构化日志中的模型证据提取，拒绝以模型文字自报作为证据。
